# README — How to use this package in Claude Design

## Files in this package

1. `ZOLAQ_STEP_5_FINAL_CORRECTION_BRIEF.md`
   - Final source of truth for Step 5 correction.
   - Upload this as context.

2. `CLAUDE_LIMIT_SAFE_CORRECTION_PROMPT.md`
   - Short prompt to paste into Claude Design after uploading the brief and current Zolaq project files.

## Recommended workflow

1. Open Claude Design.
2. Select `Zolaq Design System`.
3. Select `Interactive prototype` if available.
4. Upload:
   - this ZIP package;
   - previous Zolaq project ZIP / HTML if available;
   - current screenshots if needed.
5. Paste the prompt from `CLAUDE_LIMIT_SAFE_CORRECTION_PROMPT.md`.
6. Send.

## Important

Do not ask Claude to restart from zero.
Do not ask Claude to redesign the visual direction.
The task is only Step 5 Final Correction: architecture, flow, states, terminology, CTA hierarchy, price/source logic, and missing P0 screens/states.
